# Shoppn — E-Commerce Lab (Vanilla MVC Pathway)

A server-rendered e-commerce app built with HTML, CSS, JavaScript, PHP and MySQL,
following a strict MVC structure (Model in classes/, View in views/, Controller in
controllers/, Core in core/, Actions in actions/).

## Setup
1. Import `database/shoppn.sql` into MySQL.
2. Copy `db_cred.example.php` to `core/db_cred.php` and fill in your credentials.
3. Visit `index.php` in your browser.

## Tasks completed
- Task 1: Database setup
- Task 2: Folder structure & core files
- Task 3: Customer registration
- Task 4: Customer login & access control
